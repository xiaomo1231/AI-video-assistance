## 1. 一句话定位

一个本地运行的桌面视频工作台：AI 帮你从一句话需求做到成片，你在同一个软件里看、改每一个镜头、每一句提示词、每一段配音和配乐，还能像剪辑软件一样剪、像达芬奇一样调色。整条制作流程是你自己定义、可以保存复用的「工作流」。

**它要解决你在「先问我宣传片」实操里遇到的问题**：

| 实操里发生的事 | 软件里怎么解决 |
| --- | --- |
| 深色模式下字看不清，来回两次才修好 | 导出前自动做可读性检查（对比度、字号、停留时长），渲染页面固定配色，不跟随系统主题 |
| 卡片和小墨互相遮挡、头发融进背景 | 画面圈注：在预览上框出问题，写一句话，AI 只改这一处；外加文字与主体的遮挡检测 |
| 想换 MiniMax 配音，要先找网络设置、再等全部重做 | 配音页按段管理，换接口、换音色、单段重做、上传自己的录音并自动对齐 |
| 「看完觉得没问题就开始做」，每次都要等 AI 出一整页样片 | 分镜卡片墙 + 时间线实时预览，改了马上能看，改动以版本形式保存，可对比、可回退 |
| 9 轮来回全靠截图和文字描述 | 工作流里有「审片」节点：不通过就带着圈注回到分镜节点，过程留档 |
| 录音稿要手动整理、按段号命名文件 | 一键导出录音稿，录完的文件拖回来按段号自动替换并重新对齐镜头时长 |

## 3. 调研结论

| 项目 | 是什么 | 我们学什么 | 不学或要注意什么 |
| --- | --- | --- | --- |
| **lemo-opuscar** | 66 种影片风格的 skill。每部片子是一个按时间渲染画面的网页（`render(t)`），配台词表 `lines.json`、节拍表 `timeline.json`、配乐和混音脚本，`build.sh` 一键导出 | 「一条时间线驱动一切」的结构；导演方法（DIRECTOR.md）可以直接做成工作流节点的提示词；可读性检查 `readcheck`、听写校验 `asr_check` 这类自检 | 代码 MIT，样片 CC BY 4.0，可以用，需署名。它针对 Claude 调校，换别的模型效果可能下降，软件里要提示 |
| **EAC design world** | DeepSeek Harness 的视频与设计插件，也能独立运行。多轨时间线、参数化调色（曲线、HSL、LUT、示波器）、剪映/FCP XML 导出、MCP 工具、库存素材搜索 | 功能清单最接近你要的；「AI 改参数 + 示波器数值护栏」的调色迭代方式；MCP 工具设计；长任务用任务号轮询 | **AGPL-3.0**。只参考设计，不复制代码，否则我们的软件也必须用 AGPL 开源 |
| **video-shotcraft** | 150 个动效镜头配方，基于 Remotion；自带剪映式「动效工作台」，成片按镜头拆成多轨可继续改；能导出剪映草稿 | 镜头库作为素材库的一个分类，可拖上时间线；「成片拆成多轨再编辑」的接入契约；剪映导出 | Apache-2.0 可用。它依赖的 Remotion 有自己的许可，公司规模超过一定人数要买授权；我们自己的渲染器不依赖 Remotion，只在接入 shotcraft 时调用 |
| **mg-styles-15** | 15 种 MG 风格，每种一支 10 秒片；`renderAt(t)` 网页 + `cues.json` 节拍 + `audio.py` 合成配乐；用第二个 AI 按评分表审片两轮 | 「AI 评审员」节点：另一个模型按评分表打分并给修改意见；风格提示词可导入提示词库 | MIT，可用 |
| **ChatCut** | 对话式 AI 剪辑器。这次官网被云端网络拦住没打开，以下按已知信息：用聊天下剪辑指令、按文字稿剪辑、自动字幕、去口误和停顿 | 右侧常驻 AI 助手，所有修改先出「修改建议」再一键应用；vlog 用文字稿剪辑 | 需要时你可以在网络设置里放行 chatcut.io，我再补一次详细对比 |
| **达芬奇 Resolve** | 专业剪辑调色软件，按页面分区：媒体、剪辑、调色、音频、交付 | 页面分区的心智模型；一级调色轮（Lift / Gamma / Gain / Offset）、曲线、HSL 限定器、节点、LUT、示波器 | 不追求 Fusion 合成、动态跟踪、Fairlight 多总线这类重型能力，第一版明确不做 |

**结论**：市面上已有的工具要么偏「AI 一键生成」，改起来要回到对话；要么偏「剪辑器」，不懂 AI 生成的结构。我们做中间那层：工程文件同时保存 AI 生成用的结构（分镜、提示词、台词、节拍）和剪辑用的结构（轨道、片段、关键帧、调色），两边改的是同一份数据。

### 3.1 怎么调研效果更好

上一版的调研主要是读仓库和官网介绍，这样只能知道「有什么功能」，不知道「好不好用」。这一版之后按下面四步做，每一步都有产出：

1. **拆解产品，而不是读介绍**。对剪映、ChatCut、Descript、OpenChatCut、shotcraft 工作台，各录一段完整操作，记录：从打开到第一次出片要点几下、时间线上每个按钮做什么、出错怎么撤回。产出是一张「交互对照表」，直接决定我们剪辑页的按钮和快捷键（5.3 就是这样来的）。
2. **用你的真实项目跑一遍**。把「先问我宣传片」的同一份需求，分别在 ChatCut（对话剪辑）、剪映（手工剪）和 lemo-opuscar（对话生成）里各做一次，记录总耗时、来回轮数、哪一步最卡。你那次是 9 轮，我们的目标是 3 轮以内。
3. **定基准任务，每个版本都测**。固定 8 个任务，每次发版都计时：
   - 一句话需求到第一版样片
   - 把第 8 句配音换成更活泼的语气
   - 某个镜头的字看不清，修好
   - 整片调暖并保持肤色
   - 把 5 分钟横版切成 3 条 30 秒竖版
   - 删掉口播里所有「嗯」「啊」
   - 换一个风格模板重出
   - 导出 MP4 和 MOV 并通过体检
4. **看用户怎么说**。剪映和 ChatCut 的应用商店评论、小红书和 B 站「剪映技巧」高赞内容，统计大家最常抱怨和最常夸的点，抱怨的我们避开，夸的我们照做。

**这次已经确认的结论**：

- **剪映**好用在三点：主轨磁吸（删一段后面自动补上）、素材库和属性面板固定在左右两侧不遮挡、播放头和预览轴分开（鼠标划过就能看画面，不用拖播放头）。这三点都放进了 5.3。
- **ChatCut**（chatcut.io）的核心是 Skill：每个 Skill 是一个打包好的剪辑任务（去口误、加字幕、长切短、仿拍、产品广告、翻译配音等），用户选一个、给素材、AI 执行，结果落回时间线可以继续手改。我们照这个思路做开始页和第一批 Skill（7.1）。官网在云端网络里被拦，这部分来自搜索结果和公开介绍。
- **Descript** 的文字稿剪辑最成熟：删字即删画面、一键去口误。对应我们的「按文字稿剪辑」和「去口误和停顿」两个 Skill。
- **OpenChatCut** 是 ChatCut 的开源仿制，AGPL 许可，只看思路不用代码。
- **shotcraft 工作台**证明了「成片拆回多轨继续改」可行，我们的 AI 产出一律落成可编辑的轨道，不出一个不能改的整片。

## 4. 核心概念与数据模型

一个工程就是一个文件夹，用 git 管理版本：

```
先问我宣传片/
  project.json        工程总表：画幅、帧率、轨道、片段、调色、导出设置
  shots/              每个镜头一份：提示词、镜头语言、参数、状态、批注
  scenes/             代码场景（render(t) 网页），来自 lemo-opuscar 等
  media/              你自己的素材：录屏、照片、实拍
  audio/              配音（按段）、配乐、音效
  workflow.json       这个工程用的工作流
  out/                成片、字幕、录音稿
  .history/           版本快照（git）
```

**关键对象**：

- **镜头（Shot）**：时间线上的一段，也是分镜卡片墙上的一张卡。带画面提示词、镜头语言、台词、角色、状态（制作中 / 待修改 / 已确认）、批注。
- **片段（Clip）**：轨道上的一个元素。类型有：媒体片段、代码场景、字幕、配音、音乐、音效、调整层。
- **代码场景（CodeScene）**：一个实现了 `render(t)` 的网页，加一份参数表（文字、颜色、字号、位置）。参数表让你能直接在画面上拖动和修改，而不用改代码。
- **适配器（Adapter）**：把外部格式读进来、写回去。第一版做 lemo-opuscar；之后是 video-shotcraft、mg-styles、剪映草稿、FCP XML、SRT。
- **批注（Annotation）**：时间点 + 画面上的矩形 + 一句话，挂在镜头上，AI 处理后标记已解决。

时间模型借鉴 OpenTimelineIO：轨道、片段、源入点、时长、变速。这样以后导出到其他剪辑软件不会丢结构。

### 4.1 时间模型（解决「时间对不上」）

v0.1 的问题是镜头时长、配音和字幕各自独立，改一处其他不跟着动。v0.2 的规则：

- **台词挂在镜头上**。每句台词记录它在镜头内的相对位置：配音 `off`（入点）和 `dur`（时长），字幕 `soff` 和 `sdur`。镜头挪动，台词跟着挪。
- **配音时长先估再量**。没生成配音前按字数估：`字数 ÷ 4.6 + 0.45 秒`，除以语速，对齐到帧。生成配音后换成真实时长，并用听写（whisper）校验每句都读全了。
- **镜头时长由台词推出来**。`镜头时长 = max(最短时长, 最后一句结束 + 0.9 秒留白) + 定格时长`。每句之间留 0.35 秒，第一句前留 0.5 秒。你锁定时长的镜头不自动变，超出就报警。
- **主轨磁吸**。主轨上镜头首尾相接，前面的镜头变长或删掉，后面的自动前移或后移，背景音乐和音效按镜头锚点跟着走。
- **统一时间码**。所有地方都显示 `时:分:秒:帧`（24 帧/秒），拖动、裁剪、分割都对齐到整帧。
- **体检**。导出前检查：台词有没有超出镜头、字幕停留够不够读完（不少于配音时长的 80%）、字号有没有小于 90%。

## 5. 功能模块

界面按达芬奇式的页面分区，右侧常驻 AI 助手，底部是共享时间线。demo 里六个页面都能点。工作流页见第 7 节。

### 5.0 开始页（Skill + 风格模板）

打开软件先到这里，目标是「不看教程也能出第一版」：

- **左边 Skill 列表**，按生成、剪辑、包装、质检分组，默认选中「★ 一句话生成宣传片」。
- **中间模板墙**，30 个风格模板，每个有样张、适用场景、来源和许可；可按类别筛选，可搜索「手绘」「美漫」「水墨」。
- **右边向导**：选中的 Skill 需要填什么（一句话需求、时长、画幅、配音），选中的模板，接下来会跑的步骤，以及「开始制作」。
- 点「开始制作」后，按 Skill 的步骤依次执行；遇到人工确认节点就停下打开对应页面（分镜或剪辑）。点「看工作流」可以先看、先改步骤。

### 5.1 分镜页

- 卡片墙按章节分组，缩略图是真实渲染帧，不是示意图。
- 右侧检视面板：标题、画面提示词、镜头语言、台词与角色、时长、字号、状态。
- 「AI 按提示词重做」只重新生成这一个镜头。
- 也可以切换成表格视图，方便一次看全部台词和时长。

### 5.2 提示词库

- 三类提示词：风格提示词（lemo-opuscar 的 STYLE.md、mg-styles 的风格说明）、镜头提示词（每个镜头的画面描述）、流程提示词（工作流节点里给 AI 的指令）。
- 版本化，可以对比两版提示词生成的结果。
- 支持变量，例如 `{产品名}`、`{主色}`，换项目时一处替换。

### 5.3 剪辑页（照剪映的布局）

**布局**：左素材库，中播放器，右属性面板，下时间线。四块固定不遮挡，AI 助手从最右侧展开。

**左：素材库**，八个分类：媒体（本工程镜头和导入素材）、音频、文本（字幕和花字模板）、镜头库（shotcraft 配方）、转场、滤镜、音效、贴纸。每项悬停出现「＋」，点了加到播放头位置；也可以直接拖到轨道上。

**中：播放器**。时间码 `时:分:秒:帧`，逐帧前后（← →），播放暂停（空格），「圈注问题」在画面上框一块交给 AI，「体检」跑导出前检查。

**右：属性面板**，跟着选中的片段变：

| 选中 | 标签页 |
| --- | --- |
| 画面片段 | 画面（标题、提示词、镜头语言、字号、镜像）· 台词 · 时长（按台词自动 / 锁定 / 定格）· 动画（入场、出场、转场）· AI（按提示词重做这一镜） |
| 配音 | 配音（接口、音色、语速、情绪、单句重做、上传录音）· 字幕 |
| 字幕 | 字幕（文字、样式、停留时长）· 配音 |
| 文字 | 文字（内容、样式、入出场） |
| 音乐 | 音乐（换曲、音量、淡入淡出、闪避） |
| 音效 | 音效（换音效、音量） |

**下：时间线**。轨道从上到下：文字、字幕、**主轨**（更高，带缩略图）、配音（带波形）、音乐、音效。每条轨道头有锁定和静音/隐藏。标尺有大小刻度和章节标记。

工具栏和快捷键：

| 按钮 | 快捷键 | 做什么 |
| --- | --- | --- |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Shift+Z | 任何改动都能撤 |
| 分割 | S | 在播放头处切开选中片段 |
| 向左裁剪 / 向右裁剪 | Q / W | 删掉播放头左边或右边的部分 |
| 删除 | Delete | 主轨磁吸开着时，后面自动补上 |
| 定格 | 无 | 在镜头末尾加 2 秒定格 |
| 镜像 | 无 | 左右翻转画面 |
| 主轨磁吸 | 无 | 主轨镜头首尾相接 |
| 吸附 | 无 | 拖动时吸到播放头、片段边缘、章节点 |
| 联动 | 无 | 移动镜头时台词、字幕、音效一起走 |
| 预览轴 | 无 | 鼠标划过时间线就预览画面，不动播放头 |
| 缩放 / 适配 | Ctrl+滚轮 / Shift+Z | 缩放时间线，或一屏看全整片 |

剪辑软件的其他基础能力（第一版都做）：跨轨拖动、复制粘贴、变速、倒放、关键帧（位置、缩放、旋转、不透明度，带缓动）、调整层、标记点、多版本时间线、文字稿剪辑、自动字幕（烧录或另存 SRT）。

### 5.4 调色页

参照达芬奇的基础调色：

- 一级调色：Lift / Gamma / Gain / Offset 色轮，曝光、对比度、饱和度、色温、色调。
- 曲线：主曲线、RGB 曲线、色相对色相、色相对饱和度、亮度对饱和度。
- HSL 限定器 + 简单的形状蒙版（圆形、矩形），用于局部调色。
- 节点：串行节点，可开关、可重排；第二阶段再做并行节点。
- LUT：导入 `.cube`，把当前调色导出成 `.cube`。
- 示波器：亮度波形、RGB 分量、矢量示波器、直方图。
- 调色前后对比（分屏）、镜头间复制调色、AI「匹配这两个镜头的颜色」。
- 预览用 GPU 着色器实时计算；导出时用同一套着色器逐帧处理，保证所见即所得。

### 5.5 音频页

- 配音按段管理：角色、台词、音色、接口、情绪、语速，每段可以单独重做。
- 每段生成后自动用 faster-whisper 听写校验，和台词对不上会标出来。
- 支持上传自己的录音：按段号命名或自动识别，替换后按你的语速调整镜头长度。
- 配乐三种来源：程序合成（lemo-opuscar 的采样器）、本地曲库、音乐接口（用户自配）。
- 音效：按画面事件自动对齐，例如盖章、弹出。
- 混音：每轨音量、说话时自动压低音乐、响度 -14 LUFS。

### 5.6 版本与对比

- 每次 AI 改动、每次导出都自动存一个版本，手动也可以存。
- 两个版本并排播放或上下分屏，差异列表（哪些镜头、台词、调色变了）。
- 任意版本一键回退，或者只把某一个镜头回退到旧版本。

### 5.7 交付页

- MP4：H.264（兼容性最好）、H.265。MOV：ProRes 422 HQ、ProRes 4444（带透明通道）、H.264。
- 画幅：16:9 横版、9:16 竖版、1:1，4K / 1080p；帧率 24 / 30 / 60。
- 导出前自动检查：可读性、遮挡、配音听写、黑帧空白帧、响度。
- 同时输出 SRT、录音稿、工程交接文件（剪映草稿、FCP XML，第二阶段）。

### 6.5 安全与预算

- 密钥存在系统钥匙串（Windows 凭据管理器、macOS 钥匙串），不写进工程文件，也不进 git。
- 每个提供商单独设置月度上限和提醒线，超限前暂停并问你。
- 本地记录每次调用的模型、用量和估算费用。

### 6.6 「修改建议」交互

AI 的每次修改都先以修改建议的形式出现：改哪个镜头、改什么、前后对比，你点「应用」才生效，并且可以撤销。demo 右侧 AI 助手演示的就是这个。

### 6.7 AI 改片循环

AI 不直接改工程，每次都走同一个循环，这样每一步都能看、能撤：

1. **读上下文**：当前页面、选中的镜头或片段、播放头时间、圈注框、体检结果，通过 MCP 工具 `project_read` 拿到。
2. **出修改建议**：以差异的形式列出要改什么（例如「S01 字号 100% → 130%，文字颜色固定 #2B1D16」），不超过一屏。
3. **你确认**：应用、不用了，或者改一下再应用。
4. **执行并局部重渲**：只重渲改到的镜头，配音只重做改到的句子。
5. **自检**：跑体检和听写校验，不通过就自己再改一次，两次还不行就停下告诉你。
6. **记版本**：每次应用都存一个版本，可以和上一版并排对比。

## 7. 工作流引擎（产品核心）

工作流是一张节点图，描述「一部片子从需求到交付怎么做」。每个人、每类片子可以有自己的工作流。

**节点类型**：

- **AI 步骤**：调用某个模型，带提示词模板和 skill（例如 lemo-opuscar 的 DIRECTOR.md），输出写进工程。
- **工具**：渲染样片、配音、配乐、混音、导出、检查。
- **人工确认**：暂停等你看，可以选「通过」或「带着圈注打回」。
- **AI 评审**：另一个模型按评分表打分（来自 mg-styles-15 的做法），低于阈值自动打回。
- **条件 / 循环**：比如「审片不通过就回到分镜方案，最多 5 轮」。

**内置模板**（第一版）：

1. **lemo-opuscar 宣传片**：照你那次实操整理。需求简报 → AI 提问 → 分镜方案 → 渲染样片 → 审片圈注（不通过回到分镜）→ 配音 → 配乐与音效 → 成片渲染 → 交付。demo 的工作流页就是这条。
2. **产品录屏宣传片**（shotcraft 风格）：抓取页面 → 挑镜头配方 → 分镜 → 卡点 → 导出。
3. **vlog 粗剪**：导入素材 → 语音转文字 → 按文字稿粗剪 → 去停顿 → 配乐 → 字幕 → 调色 → 导出。
4. **短视频切条**：长片 → AI 找高光 → 裁成竖版 → 加字幕和标题 → 批量导出。

工作流存成 `workflow.json`，可以导出分享、导入别人的。每次运行都留日志：哪个节点、用了哪个模型、花了多少、产出了什么。

```
│   AI 接入层（API / Token Plan / CLI 子进程） · MCP 服务 · 钥匙串        │
├──────────────────────────────────────────────────────────────────────┤
│ 工作进程                                                               │
│   渲染：离屏 Chromium 逐帧截取 render(t)，多进程并行                    │
│   编码：FFmpeg 7（H.264 / H.265 / ProRes），两遍响度标准化              │
│   Python 附加组件（可选）：faster-whisper 听写、采样器配乐、本地 TTS    │
└──────────────────────────────────────────────────────────────────────┘
```

**为什么选 Electron 而不是 Tauri**：代码场景本质上是网页，预览和导出必须用同一个浏览器内核才能逐帧一致；Electron 自带 Chromium，Tauri 在 Windows 上用 WebView2、在 macOS 上用 WebKit，两边渲染会有差异。参考的四个项目也都是 Node 生态，可以直接复用。代价是安装包大一些（约 150 MB）。

**技术选型**：

| 部分 | 选择 |
| --- | --- |
| 桌面框架 | Electron + electron-builder（Windows 安装包，之后 macOS 签名公证） |
| 界面 | React 18 + TypeScript + Zustand 状态管理 + Vite |
| 时间线 | 自研（Canvas 绘制，保证上千个片段也流畅） |
| 预览与调色 | WebGL2 着色器；示波器在 GPU 上计算 |
| 渲染导出 | 离屏 Chromium + FFmpeg，内置 FFmpeg 可执行文件 |
| 语音转文字 | faster-whisper（Python 附加组件，首次使用时下载） |
| 工程版本 | isomorphic-git |
| 密钥 | Electron safeStorage + 系统钥匙串 |
| 测试 | Vitest（单元）+ Playwright（界面）+ 像素对比（渲染一致性） |

## 10. 风险与待定事项

- **风格质量依赖模型**：lemo-opuscar 针对 Claude 调校，换成其他模型画面质量可能明显下降。软件里给每个风格标注「推荐模型」。
- **许可**：EAC 是 AGPL，只参考不复制；shotcraft 依赖 Remotion，Remotion 对公司有授权要求；lemo-opuscar 的样片要求署名。以后如果要商用或开源，需要先定我们自己的许可证。
- **渲染速度**：5 分钟 1080p 逐帧渲染在普通电脑上大约 10 到 20 分钟，需要并行和增量渲染（只重渲改动的镜头）。
- **「剪辑软件的功能都要有」**：范围很大。第一版做到第 5.3 节列的基础能力，多机位、动态跟踪、抠像、Fusion 级合成这类不在计划里，需要的话我们再排期。
- **名字**：「墨剪」是暂名，你定了我全局替换。

## 11. Demo 说明

`demo/index.html` 是界面原型，用你上次的「先问我宣传片」做示例工程（15 个镜头，33 句台词，约 2 分 14 秒，时长按台词自动算出）。可以操作的部分：

- **开始**：左边 16 个 Skill，中间 30 个模板（可筛选、搜索），右边向导；点「开始制作」模拟运行并打开分镜页，点「看工作流」打开这个 Skill 的步骤图。
- **工作流**：按选中的 Skill 生成节点图，审片不通过的回路用黄色虚线标出；可以加节点、改配置、运行、存成我的 Skill。
- **分镜**：卡片墙，改标题、提示词、台词，台词改长了镜头自动变长，后面的镜头自动后移。
- **剪辑**：剪映式布局。拖动、裁剪片段，分割（S）、向左/右裁剪（Q/W）、删除、定格、镜像，主轨磁吸、吸附、联动、预览轴开关，缩放和适配，撤销重做；属性面板随选中片段切换；圈注和体检。
- **调色**：色轮、滑杆、LUT、波形和 RGB 分量、前后对比、复制调色到其他镜头。
- **音频**：每句一行，换音色、单句重做、听写校验状态。
- **交付**：MP4 / MOV、编码、分辨率、帧率，导出前体检逐项显示结果。
- **AI 助手**：快捷问题或自己输入，回复是预设的，用来展示「修改建议 → 应用 → 可撤销」。

Demo 里的画面是简化版的 `render(t)`，真实版本会直接加载 lemo-opuscar 渲染的场景。
