# 墨剪（暂名）· AI 视频工作台

本地运行的桌面视频工作台：AI 从一句话需求做到成片，你在同一个软件里查看和修改分镜、提示词、配音、配乐，做基础剪辑和调色，并用自己定义的工作流把整个过程串起来。

- 方案：[docs/方案.md](docs/方案.md)
- 界面 demo：[demo/index.html](demo/index.html)，浏览器直接打开即可

- 桌面应用：[app/](app/README.md)，`cd app && npm install && npm run build && npm start`

当前阶段：v0.1 可用版。开始页、工作流、分镜、剪辑时间线、调色、音频、交付、设置都已接上真实工程文件；示例工程可以直接导出 MP4。
